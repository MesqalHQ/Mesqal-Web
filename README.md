## 🌍 Overview

Mesqal is a modern web application designed to provide fast and clean access to financial market information.

Track:

- 💵 USD, EUR, GBP and other currencies
- 🪙 Gold prices
- ₿ Cryptocurrencies
- 📈 Historical charts
- 🔥 Market trends
- 📊 Daily & Monthly analytics
- 💰 Affordability calculations
- 📅 Financial calendar views

Mesqal focuses on delivering useful information through a minimal, responsive, and aesthetically pleasing interface.

---

## ✨ Features

### 📊 Interactive Charts

Visualize market changes with responsive charts and trend indicators.

### 🔥 Heatmap View

Quickly identify market movements and performance changes.

### 📋 Data Tables

View raw financial data in a clean tabular format.

### 💰 Wallet Simulator

Monitor and compare asset values across different currencies.

### 📅 Calendar Analytics

Review historical price changes by date.

### 🛒 Affordability Calculator

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/MesqalHQ/Mesqal-Web.git
cd Mesqal-Web
```

Run a local server:

```bash
python -m http.server 8000
```

Or use:

```bash
npx serve .
```

Open:

```text
http://localhost:8000
```
